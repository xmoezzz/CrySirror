# System-NNN native adapter

This first-class crate implements the original word-addressed SPT VM and thin
native policies. Expressions, variables, structured control and script transfers
run on cancellation-aware workers. Only the owner commits client-scoped engine
calls and acknowledges the exact pending native receipt. Unknown operations keep
their original PC and fail explicitly.

`installed` (feature `runtime`) supplies a dormant factory. First step admits
capability-based bootstrap work; it reads original MSI/configuration/script data,
verifies the reviewed callback module SHA and prepares engine-owned resources.
No original executable or embedded engine core runs. The desktop detects the
reviewed installed/media profile; registration does not establish playable-game
completion.

Reusable implementation belongs to CrySirror:

- Black Cyc archives, DWQ images and VAW wrappers use the shared resource/image
  registries. Native filename, pack precedence, alpha-mask identity and
  load/preload assignment rules remain here.
- Retained Layers and frozen Canvases own composition. Immutable ImageResources,
  asynchronous canvas capture and image jobs own raster work and publication.
- SUNA uses shared persistent temporal-pattern resources and the original global
  RNG transaction. Native arguments/count/phase triggers stay here. DRAW and
  type-0 OVERRAP use those shared jobs and exact reviewed fixed-point mix rules.
- Text uses shared font measurement, fixed-cell layout, GlyphRuns and reveal;
  selections use shared UI interaction regions. Original Shift_JIS cell mapping,
  click advancement and history/window policy stay native. A translucent window
  composes through the shared mask-piecewise image operation and uses cropped
  engine image nodes, alongside separate GlyphRuns.
- Basic music/SE/voice lookup and volume policy feed shared buffered audio jobs,
  decoders and mixer. Unsupported native stepped fades, finite repeat counts and
  spatial policies fail explicitly.

The reviewed callback profile is MUGEN2 Legacy1000, 16 effect slots. Other
versions are not inferred from similar filenames. Original save envelopes can be
parsed/round-tripped without discarding opaque fields; full VM/resource restore
is still unsupported. Normal Controller startup now has original Nothing, actual shared video-header
probe, Logo and the configured Opening background SPT. The legacy DirectShow
numeric codec status is never invented; header validation does not assert full
audio decode. Movie/Title continuation remains explicitly incomplete.

`NativeAdapter` and `InstalledAdapter` expose a separate dependency-completion
pump; it does not sample input, advance clocks or schedule a new VM batch.
Shared operations also cover the exact grouped LayerGrey and masked/unkeyed
CTRANS profiles, native FadeOut11, persistent OldLamp109 and Bura74. Native six-rectangle/count/
trigger policy remains here; Bura uses shared16.16 piecewise resampling and
SUNA/Bura numeric curves map into shared progress envelopes. Original lamp Calcu
runs before all Print operations and shares the one native RNG transaction.

Ordinary picture/fill slots interleaved with screen effects are ordered shared
Composite inputs, including native picture-before-effect at the same slot. They
are excluded from the lower Canvas to avoid double rendering. Partial legacy
x86 picture masks use shared `MaskSeparate256`, with independent product floors;
window/CTRANS operations retain their distinct arithmetic profiles. No private
bitmap loop or second renderer lives in this crate.

Periodic/delay/random native curve families, moving-rectangle interpolation,
continuous effects during message waits, complete frame-debt scheduling and
later callbacks remain incomplete. Immutable player24 actually reached141
original instructions/PC0x6c2 in the ordinary startup path; the newer ordered
painter source has independent release tests and still awaits the next unified
player. Title, Start/story and full original-save restoration are not verified.

See HANDOFF.md and STATUS.md for separate implementation, release compilation
and behavior evidence. No game/font/module data or unlicensed original source
is distributed. Shared algorithms can be used without this VM.

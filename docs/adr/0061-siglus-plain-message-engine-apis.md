Date: 2026-10-26. Status: implemented bounded profile; commercial-game

## Shared capability first

`crysirror-text::grid::layout_cells` is a font-independent engine API. Its
immutable options and serializable cursor implement half cells, explicit line
breaks, caller-specified forbidden line-start punctuation, bounded hanging
punctuation, paired indentation, incremental append and explicit UTF-8 overflow.
It has no dependency on a VM. The caller owns its cursor; immutable inputs and
cloned cursors can be prepared on workers and committed by their owner.

Native messages use engine `Paint::GlyphRun`, synchronous engine font metrics
for baselines and the existing engine `GlyphReveal` scalar clock. The adapter
reads progress through client-scoped `EngineQuery::Layer`; advancing only the
VM's wall clock does not advance reveal. A completed DECIDE down-up submits
`CompleteReveal` and consumes that edge only for the current reveal.
No pixels are produced by the adapter.

## Explicit supported profile

An optional `config.message_window` specifies project font alias, message and
name rectangles, sizes, spacing and colors. This enables only the plain
horizontal `FRONT.MWND[0]` slice with `CD_TEXT` read-flag operand `-1`:

- TEXT appends cells; a later chunk retains its cursor and visible prefix.
- NAME retains the first nonempty name in the message block.
- The original VM's reveal-only wait and automatic block savepoint boundary
  remain distinct from a key wait. Native glyph/cursor records are updated.
- Runtime snapshots serialize the actual VM, cells and reveal state and must
  restore together with engine layer state. Restored window configuration is
  checked against the adapter configuration.

The plain profile is deliberately incompatible with a configured Gameexe: a
generic rectangle is not an implementation of the native Gameexe template
language. Unconfigured TEXT/NAME still fail with the existing missing-bridge
error. Markup/emoji, other MWND targets, page overflow, name wrapping, nonnegative
read-flag block commits and original-file save import/export in this profile
fail visibly. Automatic Gameexe windows, name substitutions/character colors,
backlog, ruby, vertical writing, shadow/fuchi layers, choices, page/auto/skip
policies, movies and audio are not established by this slice.

Original-save rectangle/wait coverage remains separate. In particular, retained
native glyph records do not prove correct reconstruction of original MWND save
files; the public original-file operations reject the plain message profile
instead of returning a misleading success.

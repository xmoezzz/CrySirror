
## Engine systems

Project validation, replacement and packaging understand ClientSpec.systems:
World entities, retained layers and UI widgets. Layer images use the owning
client's capability root; widget/layer fonts must be explicit licensed project
fonts when packaged.

With --executable configured, engine_trace accepts frames (1..3600), step_ms
(0..60000) and unique press_at indices. Enter pulses reach focused UI before VMs.
The result includes actual world state, UI events and service trace. scene_capture
accepts the same arguments plus renderer (raster or compute-raytrace). Both
start a new session from project data, never attach to an existing running game.
